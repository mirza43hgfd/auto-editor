# Built-in SFX library

Drop your .mp3 SFX files in this folder. Auto mode matches them by filename:

- sword.mp3 — talwar/shamsheer
- horse.mp3 — ghora/cavalry
- crowd.mp3 — bheer/army/lashkar
- wind.mp3 — hawa/desert
- drum.mp3 — dhol/naqqara/war cry
- arrow.mp3 — teer/archer
- bell.mp3 — ghanti/azan
- fire.mp3 — aag/burn
- door.mp3 — darwaza/gate
- whoosh.mp3 — sudden moves

Filenames must match `auto_pipeline.SFX_KEYWORDS` keys. Any extra mp3 here can
also be placed manually on the SFX track in Phase 2.
